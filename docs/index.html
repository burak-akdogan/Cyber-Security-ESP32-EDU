⚡ Cyber Sec ESP32 — Flash a Lab From Your Browser

Pick a lab below and click Connect. This uses ESP Web Tools to flash a pre-built firmware straight from GitHub to your ESP32 DevKit V1 — no Arduino IDE, no compiling required.

Before you start: use Chrome or Edge (desktop) — Web Serial isn't supported in Firefox/Safari. Plug in your ESP32 DevKit V1 with a micro-USB data cable, then click Connect and pick the board's serial port. Full lab guides are linked from the main README.
